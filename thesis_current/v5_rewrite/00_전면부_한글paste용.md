# 전면부 (한글 .hwp 양식 paste 용)

> **사용법.** `1. 논문규격(국문샘플).hwp` 의 각 페이지에 아래 5개 블록을 차례대로 paste.
> 양식 자체의 표·서식은 그대로 두고 텍스트만 교체. 학번/심사위원/제출일자만 마지막에 손으로 채움.

```

심사위원장   ○ ○ ○   인

심사위원     ○ ○ ○   인

심사위원     ○ ○ ○   인

심사위원     ○ ○ ○   인



2026년 5월


호 서 대 학 교  대 학 원
```

> **NOTE — 심사위원.** 박사학위는 보통 5인. 위원장 + 4인의 이름은 심사 일정 확정 후 손으로 기입.
> 호서대 박사 인준서는 5인 항목이 양식에 미리 인쇄되어 있을 가능성이 높음 — `1. 논문규격(국문샘플).hwp` 가 석사 (3인) 샘플이므로 박사 양식은 학과 사무실 또는 융합대학원 사이트에서 별도 확인.

## 페이지 5 — 목차 (자동 생성)

> **사용법.** 한글의 자동 목차 기능을 사용. 본문(v22 docx)의 Heading 1/2/3 이 양식 .hwp 의 스타일과 매핑되면 한 번에 생성됨.
>
> 매핑 매뉴얼:
> - `Heading 1` (Ⅰ. 서론, Ⅱ. 관련 연구, …) → 한글 양식의 "장 제목" 스타일
> - `Heading 2` (1. 연구 배경, 2. 연구 문제, …) → "절 제목" 스타일
> - `Heading 3` (가. 방법론적 기여, 나. 실증적 기여, …) → "항 제목" 스타일
>
> 매핑이 자동으로 안 잡히면 한글에서 [도구] → [스타일] → [스타일 마당] 으로 일괄 적용.
